Prometheus Cognitive Engine

Built an AI-native automotive ALM and cognitive-engine platform for embedded-software workflows. The goal was to compress the distance between product definition, requirements engineering, code scaffolding, traceability, and execution support.

The core idea was simple: engineering knowledge should not stay trapped in documents, tools, and individuals. It should be queryable, reusable, and production-oriented.

  • Covered grounded Q&A, requirements generation, code and HMI scaffolding, and project-execution support.
  • Used FAISS-backed semantic memory, reasoning memory, screenshot understanding, and planning workflows across documents, images, and structured engineering context.
  • Applied the platform to standards-aware workflows aligned with ASPICE, ISO 26262, ISO 21434, and AIS 189.

Granted Patents

The patent portfolio reflects repeated work at the overlap of connected mobility, charging infrastructure, rider safety, metering, cybersecurity, diagnostics, and data integrity. Top 4 patents by value creation for Matter
IN573730

On-vehicle security measures system

Granted
Application No: 202421034485 Division: Software/Digital Sub Division: Data Security

Secures a connected network through a gateway controller that analyzes communication logs, detects errors and delay patterns, and dynamically controls communication paths. The business value is direct: it creates protectable IP around adaptive on-vehicle cybersecurity at the network-control layer, which is highly relevant for connected EV architectures.

IN575042

System to track and verify message integrity in an avionics communication network

Granted
Application No: 202421024553 Division: Software/Digital Sub Division: Data Security

Uses blockchain-linked logging and cryptographic hashes to verify end-to-end message integrity and localize message loss. Its value comes from protecting traceable, tamper-aware communication integrity mechanisms that matter in safety-critical distributed networks.

IN552912

System and method for detecting safety headgear of user operating a vehicle

Granted
Application No: 202221060355 Division: Software/Digital Sub Division: Headgear

Tracks the position and orientation of safety headgear using vision sensing and reference-point monitoring. This is valuable because it connects rider safety, sensing, and smart-vehicle interaction into a differentiated product capability instead of a generic accessory feature.

IN536810

System and method for charging electric vehicle and computing cost associated with charging event

Granted
Application No: 202221036924 Division: Software/Digital Sub Division: Charging event

Combines charger identification, power-grid parameter detection, charging-event data, and cost computation into a single charging-cost workflow. It matters commercially because it strengthens the company's position in transparent charging economics and user-facing charging intelligence.
