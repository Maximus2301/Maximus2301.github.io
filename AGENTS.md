# Agent Workflow

These instructions apply to all future Codex sessions in this repository.

## Required Start-of-Session Steps

1. Read `PROJECT_SUMMARY.md` before making changes.
2. Review the latest entry in `SESSION_LOG.md` for recent context.

## Required End-of-Session Steps

1. Append a new dated entry to `SESSION_LOG.md`.
2. Include:
   - objective
   - key changes made
   - files changed
   - verification performed
   - open follow-ups, if any
3. Do not delete or rewrite previous session entries unless explicitly asked.

## Project Expectations

- Keep the site static: HTML, CSS, and minimal vanilla JavaScript only.
- Preserve the three-page structure: `Resume`, `Portfolio`, and `About Me`.
- Maintain the editorial visual direction already established in the site.
- Prefer updating `PROJECT_SUMMARY.md` when the site structure, theme, or content strategy changes materially.
