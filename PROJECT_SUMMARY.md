# Project Summary

## Purpose

This repository hosts the public GitHub Pages portfolio for Pankaj Kumar Bharti. The site is positioned for senior product, AI-platform, connected mobility, EV, OTA, and software-defined vehicle opportunities.

## Current Site Structure

- `index.html`
  - Resume-style landing page
  - Hero with contact details and headline metrics
  - Left sidebar for profile, skills, education, and signals
  - Main column for work experience
- `portfolio.html`
  - Narrative portfolio page
  - Dedicated sections for:
    - Prometheus Cognitive Engine
    - Agentic RAG for issue intelligence
    - Manufacturing validation and digital traceability
    - Connected mobility portfolio
    - Granted patents with top-4 value-creation highlights and all-12 summaries
    - Signals and reflection
- `about.html`
  - Personal positioning page
  - Six-card narrative layout
  - Belief statement
  - "Currently" grid

## Design Direction

- Theme benchmarked against `https://monanibrinda.github.io/`
- Typography:
  - `Playfair Display` for editorial headings
  - `Instrument Sans` for body copy
- Color system:
  - black background accents
  - warm amber highlights
  - off-white page background
  - soft neutral rules and cards
- Header:
  - sticky dark top navigation
  - three-page navigation only

## Content Strategy

- Resume page should remain concise and recruiter-friendly.
- Portfolio page should contain the deeper project and case-study material.
- About page should explain working style, operating principles, and positioning.
- Resume PDF should stay available at `assets/docs/pankaj-kumar-bharti-resume-202604.pdf`.

## Technical Notes

- Static site only
- No framework
- No build step
- Main shared assets:
  - `assets/css/styles.css`
  - `assets/js/site.js`
  - `assets/images/pankaj-kumar-bharti.png`

## Deployment

- GitHub Pages deploys from the `main` branch.
- Relative links are used so pages work correctly on GitHub Pages.

## Maintenance Guidance

- If a future session changes site structure, navigation, or theme, update this file.
- If a future session adds a major project or changes positioning, reflect it here before ending the session.
